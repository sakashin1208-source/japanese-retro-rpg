## 2. 未対応で残っている課題

### ⑤ テクスチャフィルタが Nearest のまま

**該当**: `project.godot:124` `textures/canvas_textures/default_texture_filter=0`

SPEC §12 B-10 で「本作はグラデーション主体の描画であり、最近傍法にすると縮小時に劣化する」と確定済みだが、Nearest が維持されている。改修設計案は「ドット絵をピクセルパーフェクトに描画するため維持」と記載するのみで、確定仕様との差異についての判断根拠が示されていない。

**影響**: `stretch/mode="canvas_items"` では2D内容がウィンドウ解像度で直接ラスタライズされるため、非整数倍スケール（ほぼ全てのウィンドウサイズ）でスプライトのピクセルが間引かれ、移動時にちらつく。

**選択肢**:

| 案 | 設定 | 得失 |
|---|---|---|
| A | `default_texture_filter=1`（Linear） | 縮小が滑らか。確定仕様と整合。ドットのエッジは甘くなる |
| B | `stretch/mode="viewport"` ＋ Nearest | 真のピクセルパーフェクト。整数倍以外では黒帯が増える |
| C | 現状維持 | 判断として有り得るが、**SPEC §12 B-10 を改訂して根拠を残すこと** |

いずれを採るにせよ、確定仕様と実装が食い違ったまま放置しないことを推奨する。

## 3. フォントのグリフ収録検証（実測）

`fonttools` が利用できない環境のため、**TTFのcmapテーブルを標準ライブラリで直接解析**し、本作が使用する全文字の収録状況を実測した。

| 検査対象 | 検査文字数 | 結果 |
|---|---|---|
| `assets/data/master_data.json` 全文 | 658字 | **全収録** |
| GDScript内の日本語リテラル | 554字 | **全収録** |

- フォント: `DotGothic16-Regular.ttf`（2,069,236 bytes）
- 収録コードポイント数: **8,231**
- `咫`（八咫の鏡）`瓊`（八尺瓊勾玉）`譚`（妖幻奇譚）`薙`（草薙の剣）等の第2水準漢字を含め欠落なし

**結論: 豆腐(□)化しない。** ライセンスもSIL OFLで商用利用可であり、選定は妥当。

> 再検証が必要な場合は、master_data.json とGDScriptから文字を収集し、cmap（format 4 / 12）と突き合わせる方式で再現できる。フォント差し替え時は必ず再実行すること。

## 4. 申し送り事項

### (1) `window/stretch/aspect="keep"` が作業ツリーで消えている

コミット済みの `godot/project.godot` には `window/stretch/aspect="keep"` があるが、**未コミットの作業ツリーでは削除されている**。Godotエディタがプロジェクトを保存する際、エンジン既定値と一致する設定を省略するためと推測される（＝既定値が `keep` である可能性が高い）。

意図的な変更ではない可能性があるため、**コミット前に意図を確認すること**。4:3維持を仕様として保証したいなら、既定値と同値でも明示的に残す方が安全である。

### (2) 未pushのコミットが存在する

本報告書作成時点で `main` は `origin/main` より **4コミット先行**している。push は外部送信にあたるため、オーナー承認のうえで実施すること。

### (3) 検証できていない範囲

- **Godot本体が未インストールのため、統合テスト（申告73件）は実行していない。** 本レビューは静的解析・設定ファイル・アセット実体の照合に基づく
- 実機での日本語表示・描画品質の目視確認も未実施。フォントについては §3 の静的検証で代替した

### (4) 再発防止の観点

課題④（章移動の前進のみ）は、**Web版 `MenuUI.js:118` で指摘済みの欠陥がGodot版へそのまま移植された**ものだった。移植時は、移植元で未解決の指摘事項を突き合わせるチェックを挟むと同種の持ち込みを防げる。

## 5. 総括

第1巡で検出した重大3件・中4件のうち、**未対応は⑤（テクスチャフィルタ）1件のみ**。特に以下は質の高い対応だった。

- `ui_accept` の使用を **0件** まで徹底したこと（機械的に検証可能な形で完了させた点）
- 施錠理由の文言を `MasterData` から**動的取得**する設計にしたこと。設計案の段階では実在しない「夜叉狐」等の固有名詞がハードコードされていたが、動的取得により世界観の齟齬が構造的に起きなくなった
- Theme リソース化により、フォント・サイズ・**黒フチ取り（SPEC §10.2）** を一括で満たしたこと

⑤の方針決定をもって、本移植版のレビューは完了とする。
