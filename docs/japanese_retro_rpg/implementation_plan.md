# 実装計画: 全キャラクターのグラフィック品質統一と未整備キャラ新規作成

Claude Codeのスプライト全数監査に基づき、キービジュアル（`assets/key_visual_monsters_hyakki.jpg`）水準の品質へとゲーム全体の全スプライト（ボス9体・第一章魔物20種・NPC17名・ポートレート）を一挙に刷新・新規作成し、共通基盤（輪郭線・光源・グロー・表情・構図）を導入します。

---

## ユーザー確認事項（User Review Required）

> [!IMPORTANT]
> **改修の主要ポイント**:
> 
> 1. **【第1部】共通品質向上基盤**:
>    - `createOutlinedTile(size, renderFn, outlineColor, w)` を導入し、全キャラクタースプライト（主人公・NPC・敵・ボス・ポートレート）に黒い外輪郭線を自動付与します（マップタイルは隣接敷き詰めのため除外）。
>    - `shade(hex, amt)` を導入し、「上部ハイライト／下部シャドウ」の月光セルシェーディングを徹底。
>    - `ctx.shadowColor` / `ctx.shadowBlur` による発光（グロー）効果を導入（必ず `shadowBlur = 0` でリセット）。
>    - 全キャラに目・口・表情を持たせ、128px / 192px のキャンバス余白を活かした迫力ある構図に拡張。
> 
> 2. **【第2部】個別スプライトの刷新・新規作成**:
>    - **ボス9体（192x192）**: 平均20描画コール以上の神話級・圧倒的迫力のHD-2Dデザインへ刷新。
>    - **第一章魔物20種（128x128）**: 平均4.0コールから12コール以上の高密度ドット絵・立体陰影・表情へ全面刷新。
>    - **NPC 17名（64x64）**: 使い回しを完全撤廃し、17名全員に独立した固有デザインを付与。`js/data.js` の `spriteKey` も全て固有キーに更新。
>    - **ポートレート（会話立ち絵）＆UI3層配線**: ボス9体（192x192）および主要NPC（128x128）のポートレートを新設し、会話ウィンドウ（`map.js`）に立ち絵表示枠を追加・完全配線。

## 検証計画 (Verification Plan)

1. **描画コール数全数監査スクリプト**:
   - 第一章魔物（20種）、第二章魔物（15種）、第三章魔物（15種）、ボス（9体）、NPC（17名）の各描画コール数を自動集計し、平均値を算出・比較。
2. **`createOutlinedTile` 適用確認**:
   - キャラクター系のみに適用され、マップタイルには一切適用されていないことを検証。
3. **`shadowBlur` リセット検証**:
   - `shadowBlur` を設定した全箇所で `shadowBlur = 0` が確実に実行されているかをコード静的検査。
4. **UI3層配線検証**:
   - 会話ダイアログにおけるポートレート表示が、キーボード操作・タップ操作・描画関数の3層すべてで正常動作することを自動テストで確認。
5. **初期化パフォーマンスベンチマーク**:
   - `generateAllAssets()` 全体の実行時間を計測し、初期化ラグ（体感悪化）がないことを実測。
